# 中国近现代史纲要刷题网站

>  **vibe coding**

基于 Vue 3 + Vite 搭建的刷题网站，题库来源于 `docs/question.js`，涵盖单选题与多选题。支持顺序刷题、按题型刷题、随机抽题，并在本地记录刷题数量与错题本。

## 功能
- 按顺序刷题（全部题目）
- 按题型刷题（单选/多选）
- 随机抽题（可选择数量与范围）
- 本地错题本与刷题数量统计（无需账号）, 错题答对两次自动移除
- 简洁界面，适配手机与电脑

## 使用方式
```bash
npm install
npm run dev
```

## 构建
```bash
npm run build
```

## 题库来源
题库文件存放在 `docs/question300.js`。

项目会在运行时解析题库文件并生成结构化题目数据。
